# html-gfx-website

A Next.js app that allows users to to create small custom graphics for use
as thumbnails or cards. Creating a graphic involves filling out a form to
customize size, aspect ratio, headline, subtext, font family, font color
and background color. The spec is converted to assembled into an html doc
and rendered side by side with the spec form. Finally, when the use is ready to
download what is shown in the preview panel, the user can send submit their spec
via a POST request to the backend. The backend assembles the html doc server-side
and transmits it to the renderer app running on the same network. The renderer
render the file to an image using puppeteer and then save that image to the filesystem.
The next app receives back a path to the file and then uses that to provide the
user with a download link to download their png.
