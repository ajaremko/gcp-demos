# html-gfx-infra

## Deploying

These call the matching `pulumi` commands under the hood.

```
nx deploy html-gfx-infra --stack=staging
```

```
nx preview html-gfx-infra --stack=staging
```

```
nx refresh html-gfx-infra --stack=staging
```

```
nx destroy html-gfx-infra --stack=staging
```

```
nx output html-gfx-infra --stack=staging
```
